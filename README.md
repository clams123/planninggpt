PlanningGPT est un éditeur gratuit permettant de créer facilement un planning hebdomadaire personnalisé pour Twitch et les réseaux sociaux.
Il propose de nombreux thèmes prédéfinis pour démarrer rapidement, tout en permettant de personnaliser entièrement les fonds, y compris leur transparence. 

Ajoutez vos images, textes, emojis, QR codes et effets, déplacez librement chaque élément ou utilisez le mode Random personnalisable, puis exportez le résultat en PNG. Tout fonctionne directement dans le navigateur, sans compte ni installation
