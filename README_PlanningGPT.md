# PlanningGPT V2.3.2

**PlanningGPT** est un éditeur gratuit permettant de créer facilement un planning hebdomadaire personnalisé pour Twitch et les réseaux sociaux. Il propose de nombreux thèmes prédéfinis pour démarrer rapidement, tout en permettant de personnaliser entièrement les fonds, y compris leur transparence. Ajoutez vos images, textes, emojis, QR codes et effets, déplacez librement chaque élément ou utilisez le mode Random personnalisable, puis exportez le résultat en PNG. Tout fonctionne directement dans le navigateur, sans compte ni installation.

PlanningGPT V2 associe les données structurées de la semaine à un éditeur visuel inspiré des outils de composition libre.

## Fonctionnement local

Ouvre `index.html` dans un navigateur récent. Aucun serveur et aucune connexion ne sont nécessaires. Les données du projet restent dans `localStorage` et les images personnelles dans IndexedDB.

## Vérification

Avec Node.js :

```bash
npm test
```

Les contrôles vérifient la syntaxe, la cohérence HTML/JavaScript, les modèles, les compositions de carte, les emojis, le QR local, les ressources locales et l’unicité de l’export PNG.

## Structure

- `index.html` : interface du studio.
- `v2.css` : disposition, canvas, éléments et responsive.
- `v2.js` : modèles, calques, manipulation, sauvegarde et export PNG.
- `storage.js` : stockage IndexedDB des images personnelles.
- `libs/qrcode.local.js` : génération locale du QR Code, sans service distant.
- `tests/` : contrats automatiques sans dépendance externe.
- `CHANGELOG.md` : historique synthétique.
